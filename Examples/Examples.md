# Examples

This folder contains examples for the following projects as dependencies.
- civetweb
- CLI11
- FTXUI
- FreeType
- Matplot++
- ssLogger
- SDL
- cpp-httplib

Most of them are from the official examples, or from the internet.

You can run any examples by doing `runcpp2 run <path to .yaml>`

This folder also contains an interactive tutorial for runcpp2, which is updated irregularly. 
You can start it by running `runcpp2 run ./InteractiveTutroial.cpp`
